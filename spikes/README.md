# Spikes

Throwaway prototypes built to answer one feasibility question each. They are evidence for `records/research/`, not product code.

- Each spike lives in its own directory with a `README.md` that names the question, how to run it, and which `RSH-*` memo holds the findings.
- Spikes are not built by the Xcode project and must not be imported by `Markfops/`.
- Delete a spike once its memo has captured what mattered, or when the real implementation makes it redundant.
